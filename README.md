## Design Principles

- Winrate > highlights
- Consistency > experimentation
- Utility speed > comfort binds
- MM / Faceit safe only
- Updated for current CS2 behavior

If a setting does not directly improve round outcomes, it is excluded.

---

## autoexec.cfg

Purpose:
- Reduce decision latency
- Standardize utility access
- Stabilize frame pacing
- Remove unnecessary HUD/audio noise

Highlights:
- Utility-first binds (smoke, HE, flash, molly)
- 60% keyboard / Wooting 60HE friendly
- Jumpthrow, fast stop, clean movement
- High-refresh FPS cap for consistency

---

## practice.cfg

Purpose:
- Repetition without friction
- Grenade lineup learning
- Consistency under no pressure

Includes:
- Infinite grenades
- Trajectory + impact visuals
- No freeze time
- Long round timers

Offline only.
